error(?) - Возвращает текст ошибки сценария или псевдонима. Отсылает ошибку на сервер. Может быть пустым.


| Команда | Аргументы | Описание |
| :--- | :--- | :--- |
| `error(?)` | Необязательный текст | Возвращает ошибку сценария или псевдонима. Текст ошибки отсылает на сервер. |
| `error.log(?)` | Необязательный текст | Отсылает текст ошибки на сервер. Сценарий не прерывается. |
| `info.log(?)` | Необязательный текст | Отсылает текст ошибки на сервер. Сценарий не прерывается. |
| `wait.ok(?)` | int16 (секунды) | Ожидает нажатие кнопки Ok указанное время. Если нажатия не было - возвращает ошибку **99** |
| `vmc.stop!` | - | Завершает работу программы |
| `vmc.upgrade!` | ```upgrade_script = "sudo -u vmc git -C /home..."``` | Запускает скрипт указанный в конфигурации. После успешного окончания скрипта перед сценарием ```on_front_begin``` запускает **```vmc.stop!```** |
| `check.menu` | - | Проверяет меню на ошибки. (ошибка - неправильный синтаксис или цена продажи ниже себестоимости) |
| `write.config` | - | Создает ```defaultConfig.hcl``` |
| `menu.cost` | - | Выводит текущее меню. ```code;price;cost;name;scenario``` |
| `line1(?)` | текст | выводит текст на первую строчку текстового дисплея. Вместо пробела использовать символ \_ |
| `line2(?)` | текст | вывод на вторую строку|
| `set.broken!` | - | устанавливает автомат в состояние сломан. Для сброса состояния необходимо войти в сервисное меню. Выключение питания не сбрасывает состояние|
| `picture(?)` | raw файл. Необходимо указать полынй путь | копирует содержимое в буфет экрана |
| `emulate.key(?)` | число | эмулирует нажатие кнопки клавиатуры. 0-9 цифры. 10 - C. 11 - Ok. 12 - сливки минус. 13 - сливки плюс. 14 - сахар минус. 16 - сахар плюс. 16 - точка. |
| `mdb.bus_reset` | - | сброс шины MDB. |
| `money.commit` | - | финансово считается что напиток приготовлен, и дальнейшие ошибки сценария не возвращают оплаченную сумму. Сделано для предотвращения эмуляции ошибки покупателем на финальной стадии. |
| `stock.dump` | - | - |
