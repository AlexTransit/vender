# Бункеры

- Есть два варианта исполнения.

## Hopper

адрес MDB ```40-78```

- отдельная плата для каждого бункера

у букера есть свой адрес. Каждый бункер это отденьное независимое устройство.
Бункер регистрируется уникально.

```device "evend.hopper1" { } ```

> Возможно одновременное управление несколькими бункерами.
> Из за ошибки в прошивке производителя не определяет если мотор отключен, определяет только перегрузку по току.

## Multihopper

адрес MDB ```B8```

- Одна плата на все бункеры.

Регистрация ```device "evend.multihopper"{ }``` добавляет 8 бункеров

> Одновременное управлнение несколькими бункерами невозможно.

Регистрация в конфигурации:

```yaml
hardware {
    device "evend.hopper1" { }
    device "evend.hopper2" { }
    ...
    device "evend.hopper8" { }
}
```

```yaml
hardware {
    device "evend.multihopper"{ }
}
```

## Команды

### Reset

- посылает команду сброса на устройство

```evend.multihopper.reset```

```evend.hopper1.reset```

### Run

- Задает время работы мотора. Целое число. 1 = 0.1 секунде вращения. Допустимые значения ```0-255```

```evend.multihopper1.run(?)```

```evend.hopper1.run(?)```
